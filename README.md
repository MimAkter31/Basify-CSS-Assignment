# Simple CSS Project 🎨

This is a simple CSS-based project created as part of a practice/assignment to improve layout design and styling skills using pure HTML and CSS.

🌐 **Live Preview:**  
👉 https://basify-css-assignment.vercel.app/

## ✨ Project Overview

This project demonstrates:
- Basic website layout
- Navigation bar design
- Content sections with images
- Clean spacing and alignment
- Simple yet effective CSS styling

It is focused on learning **core CSS concepts** without using any framework.
